# 每日 22:00 小复盘模板

今天英语启蒙小复盘，简单回我 5 项就行：

1. 今天做了什么？
儿歌 / 动画 / 绘本 / 生活口语 / 游戏 / 没做。

2. 大概多久？
5 分钟 / 10 分钟 / 20 分钟 / 其他。

3. 孩子反应怎么样？
愿意 / 一般 / 抗拒 / 跟唱 / 跟动作 / 主动说词。

4. 今天有没有卡点？
没时间 / 孩子不愿意 / 材料太难 / 家长不知道怎么互动 / 没有。

5. 还有什么想问的？
可以补充任何没提到的情况；没有就回「无」。

今天和原规划相比：正常 / 偏离 / 需要微调。
