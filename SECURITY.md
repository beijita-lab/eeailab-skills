## Security commitments

- No hidden telemetry.
- No automatic network requests.
- No post-install scripts.
- No obfuscated code.
- No embedded API keys, tokens, or credentials.
- No automatic reading or uploading of user files.
- No destructive commands.
- No hidden zero-width watermarking.

## Skill behavior

These skills provide educational workflows, planning templates, reasoning frameworks, and reusable prompts.
They do not execute shell commands unless the user explicitly asks the agent to do so.
